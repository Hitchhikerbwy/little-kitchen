# 第九週作業繳交草稿

標題：〔學校〕〔學號〕〔系級〕〔姓名〕 小鍋練習室

## 1. 專案簡介
「小鍋練習室」將文字食譜轉為 2D 互動網站。使用者選擇料理後，透過加入食材、翻拌、模擬等待與盛盤，依自己的步調理解料理順序。目前包含番茄炒蛋與蘑菇起司吐司兩份自編教學示例，支援搜尋、分類、進度與重玩。

## 5. 規則如何幫助 AI 繼續製作
本專案將每份食譜整理成相同格式的資料，並建立四種共用互動動作。新增食譜時，AI 先閱讀 AGENTS.md，將新素材拆解成食材與步驟，依照範本加入資料，執行驗證，再檢查完整互動流程。網站會自動呈現新食譜的卡片、分類、食材、步驟與獨立網址，因此不需要每次重新設計網頁。第二份蘑菇起司吐司沿用相同引擎，展示這套方法的延伸性。

規則範本、可複製的新增指令與擴充紀錄一併放在 docs，讓下一次製作有明確起點。現有資料為 AI 自編教學示例；實際來源食譜可依相同流程轉換，並保留來源記錄。
